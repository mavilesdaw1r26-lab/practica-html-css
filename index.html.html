            1. Cabezal obligatorio (!DOCTYPE)
            
          

          
Es la base de cualquier archivo .html. Solo se pone una vez:

          
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Aquí escribes el título de la pestaña</title>
  <style>
    /* Aquí escribes tus reglas de diseño CSS */
  </style>
</head>
<body>

  <!-- Aquí dentro va todo lo que se ve en la página -->

</body>
</html>

        


        
        

          

            2. Títulos y Subtítulos (<h1>, <h2>)
            
          

          
<!-- Aquí introduces el título principal de la página -->
<h1>Escribe aquí tu título principal</h1>

<!-- Aquí introduces un subtítulo de sección -->
<h2>Escribe aquí tu subtítulo</h2>

        


        
        

          

            3. Párrafos y Negrita (<p>, <strong>)
            
          

          
<!-- Aquí introduces tu párrafo de texto -->
<p>Escribe aquí tu párrafo y destaca lo importante con <strong>palabra en negrita</strong>.</p>

        


        
        

          

            4. Lista con puntitos (<ul>)
            
          

          
<!-- Aquí introduces los elementos de tu lista con viñetas -->
<ul>
  <li>Aquí escribes el primer punto</li>
  <li>Aquí escribes el segundo punto</li>
  <li>Aquí escribes el tercer punto</li>
</ul>

        


        
        

          

            5. Lista numerada (<ol>)
            
          

          
<!-- Aquí introduces los pasos ordenados (1, 2, 3...) -->
<ol>
  <li>Aquí escribes el paso 1</li>
  <li>Aquí escribes el paso 2</li>
  <li>Aquí escribes el paso 3</li>
</ol>

        


        
        

          

            6. Imagen (<img>) y Enlace (<a>)
            
          

          
<!-- Aquí introduces tu imagen -->
<img src="https://placehold.co/520x190/0E2A5A/ffffff?text=AI+%2B+SEO" alt="Descripción de la imagen">

<!-- Aquí introduces tu enlace clicable -->
<a href="https://www.uc3m.es">Aquí escribes el texto del enlace</a>

        


        
        

          

            7. Tabla de datos (<table>)
            
          

          
<!-- Aquí introduces tu tabla -->
<table>
  <tr>
    <th>Columna 1</th>
    <th>Columna 2</th>
  </tr>
  <tr>
    <td>Dato fila 1</td>
    <td>Descripción fila 1</td>
  </tr>
</table>

        


        
        

          

            8. Estilos CSS (dentro de <style>)
            
          

          
/* Pega esto dentro de <style> en el <head> */
body { font-family: Arial, sans-serif; margin: 25px; }
h1 { text-align: center; }
img { max-width: 100%; border-radius: 12px; }
table { width: 100%; border-collapse: collapse; background: #f3f4f6; }
th, td { padding: 14px; text-align: left; border-bottom: 1px solid #ccc; }

          GUÍA VISUAL
          
¿Qué significa cada símbolo y cada línea de código?

        

        
      


      
      

        
        

          

            1. Los símbolos que vas a ver todo el rato (Nivel 0)
          

          

            

              
< >

              
Los "paréntesis" del HTML

              
Todo lo que va entre < y > es una orden oculta (etiqueta) para el navegador. El usuario nunca ve estos símbolos en la web.

            


            

              
</ >

              
La barra de cierre

              
Funciona como un interruptor de apagar: <h1> empieza el título y </h1> le dice al navegador dónde termina.

            


            

              
palabra="valor"

              
Atributos y comillas

              
Van dentro de la etiqueta de apertura para darle datos extra, como el idioma (lang="en") o a dónde lleva un enlace (href="...").

            


            

              
{ prop: valor; }

              
Llaves, dos puntos y punto y coma

              
Solo se usan en CSS (diseño). Las llaves { } agrupan el diseño, los : asignan el valor y el ; cierra cada regla.
